# Socialcademy

A post feed. A Kodeco study project built with SwiftUI and Firebase.

## What it does

Sign in and create an account with email. The app has a post feed, a new-post form, comments, and favorites. The profile tab shows the user and a photo.

`GoogleService-Info.plist` is not in the repository. The screen will not open without your own Firebase app: download the plist in the Firebase console and add it to the **Socialcademy** target.

## Course

A Kodeco course sample. The sample was written by John Royal.

## Stack

SwiftUI, Firebase Auth, Firestore, Firebase Storage, Swift Package Manager.

## Run

```bash
git clone https://github.com/dpogonia/Socialcademy-Kodeco.git
cd Socialcademy-Kodeco
open Socialcademy.xcodeproj
```

Xcode downloads the Firebase packages on the first open. Run the **Socialcademy** scheme on an iPhone simulator.
