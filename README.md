# Socialcademy

Лента постов. Учебный проект Kodeco на SwiftUI и Firebase.

## Что умеет приложение

Вход и регистрация по почте. Лента постов, новый пост, комментарии и избранное. На вкладке профиля видны данные пользователя и фото.

Файл `GoogleService-Info.plist` в репозиторий не входит. Без своего приложения Firebase экран не откроется: скачайте plist в консоли Firebase и добавьте его в таргет **Socialcademy**.

## Курс

Пример курса Kodeco. Код примера написал John Royal.

## Стек

SwiftUI, Firebase Auth, Firestore, Firebase Storage, Swift Package Manager.

## Запуск

```bash
git clone https://github.com/dpogonia/Socialcademy-KODECO.git
cd Socialcademy-KODECO
open Socialcademy.xcodeproj
```

При первом открытии Xcode подтянет пакеты Firebase. Запустите схему **Socialcademy** на симуляторе iPhone.
